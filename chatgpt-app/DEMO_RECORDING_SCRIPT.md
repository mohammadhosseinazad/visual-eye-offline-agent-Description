# Visual Eye — Demo Recording Script

**Target duration:** 75–100 seconds  
**Status:** Recording script only. A real recording and shareable URL are still required.

## Before recording
1. Use a clean test conversation and a non-sensitive sample image that you are authorized to share.
2. Confirm the deployed MCP endpoint is awake and the app is connected in the ChatGPT test environment.
3. Hide browser bookmarks, personal notifications, account identifiers, and unrelated tabs.
4. Record the real interface; do not use mockups or edited footage that suggests unimplemented functionality.

## Shot list and narration

### 0:00–0:10 — Introduction
**On screen:** Visual Eye app name and its interface in ChatGPT.  
**Narration:** "This is Visual Eye, a guided visual-inspection workflow for ChatGPT, created by Mohammad Hossein Azad."

### 0:10–0:25 — Attach an image
**On screen:** Attach a permitted sample image directly in the ChatGPT composer, then open Visual Eye.  
**Narration:** "The user attaches an image in ChatGPT. The Visual Eye MCP service provides the interface and workflow controls; it does not upload or store the image itself."

### 0:25–0:45 — Quick review
**On screen:** Select Quick review and request a concise visual overview.  
**Narration:** "Quick review helps the user get a concise first impression and identify the most important visual observations."

### 0:45–1:05 — Deep review
**On screen:** Select Deep review and request more detailed feedback about hierarchy, composition, readability, and possible improvements.  
**Narration:** "Deep review guides a more structured discussion of composition, visual hierarchy, and design improvements. The interpretation is generated by ChatGPT's available vision capabilities."

### 1:05–1:20 — Clarify limitations
**On screen:** Show the app interface and, if useful, its privacy/terms links.  
**Narration:** "Visual Eye is a guided workflow, not a standalone computer-vision engine or an eye-tracking measurement tool. Any attention-path illustration is educational, not measured eye-tracking data."

### 1:20–1:30 — Closing
**On screen:** Visual Eye name and support contact.  
**Narration:** "Visual Eye — See more. Smile more. Support: mohammadhosseinazad3@gmail.com."

## Publishing the recording
Upload the unaltered demonstration to a video host that provides a stable, publicly accessible HTTPS URL. Test the link in a signed-out/private browser window before entering it in the submission portal. Do not include credentials, private images, or personal account information.
