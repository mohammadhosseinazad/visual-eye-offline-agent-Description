# Contributing to Visual Eye

Thank you for considering contributing to Visual Eye.

## Project principles

- Preserve attribution to the original creator, Muhammad-Hossein Azad.
- Be precise about capabilities and limitations.
- Keep the Offline Agent and hosted MCP interface documented as separate deliverables.
- Never describe heuristic attention estimates as real eye tracking.
- Never claim full offline support, security certification, or production readiness without test evidence.
- Do not commit secrets, personal images, credentials, or private deployment configuration.

## Before opening a pull request

1. Open or link an issue describing the problem or proposed change.
2. Identify which deliverable is affected: Offline Agent or ChatGPT MCP interface.
3. Include a concise rationale and expected behavior.
4. Add or update tests and documentation.
5. Record operating system, runtime, and test results.
6. Check dependency and model license implications.
7. Ensure no secrets or private user data are included.

## Pull request checklist

- [ ] Scope and affected component are clear.
- [ ] Tests are included or the reason they cannot be added is explained.
- [ ] Documentation and release notes are updated.
- [ ] Security and privacy impact is considered.
- [ ] Third-party licenses and attribution are preserved.
- [ ] No unsupported marketing or capability claims are introduced.

## Reporting bugs

Include version, commit if known, operating system, steps to reproduce, expected behavior, actual behavior, and sanitized logs. Do not attach confidential images or credentials to public issues.

## Maintainer decisions

Changes that affect ownership, license, public claims, data handling, external services, or release status require explicit maintainer review. Contributions do not transfer project ownership unless a separate written agreement says so.
